## Rule coverage in this phase
- R5.1.1 intern + active. The placement check is added in Phase 2.
- R5.1.2 radius (haversine ≤ `radius_m`), Mon–Fri 07:00–19:00:00, closure days.
- R5.1.3 device punch needs a selfie and GPS.
- R5.1.4 only `shift_in`/`shift_out`.
- R5.1.5 alternation.
- R5.1.7 system sources.
- Review: accuracy ≤ 150, one punch per 60 s, challenge, selfie object check, flags, server time.
- R5.1.6 work-log gate and R5.1.8 unscheduled capacity arrive with their tables (Phases 3–4).

## Client
- `src/lib/darwin.ts`, `minutes.ts`, `periods.ts`, `roles.ts`.
- Sign-in by email. `/reset-password` is always neutral. `/set-password`. `/consent`. Routing to the highest role's home; `/supervisor` is a placeholder until Phase 6.
- The clock desk uses `start_clock` → camera with gesture → `clock_punch`. Location is read on tap only; breaks and geocoding are removed.
- The admin desk: people by email, role checkboxes, write-only password, deactivate.
- Brand tokens in `globals.css`, Inter via `next/font/google`, and the shared components listed in build prompt §15.
- `app/manifest.ts`, icons generated by `scripts/icons.mjs` (sharp), meta CSP in the root layout.
- Deleted: `src/lib/profile.ts`, `src/lib/supabase/server.ts`, `src/lib/supabase/update-session.ts`, `supabase/functions/create-staff/`.
